# Exactory 0.91.1

This release corrects the failures of the CI of 0.91.0. It follows 0.91.0. One harness function changes: a small
math openness review is again a single turn. Every other change is under `tests/`, apart from the version and this
note. The failures and the fixes are recorded in
`misc/harness-improvement/20261113110022-every-open-record-and-review-capacity` of the exactory repository (lane
r0911-ci-fix).

## Why

0.91.0 made a new problem openness chain take the first protocol of the order `(v7, v6)` whose admission accepts its
packet. The CI of 0.91.0 failed in the general shards 2 and 3 and in the remaining checks, on Python 3.9, 3.12 and
3.14. The failures had four causes.

- The harness: the activation made the single-turn branch of `prepare_packet` refuse every openness packet. That
  rule is for a problem openness packet, whose new reviews are always chains. A math-solver openness review keeps
  `exactory-openness-reading-math-v1`, and a math packet that one input of its route holds is one native turn. In
  0.91.0, such a review became a reading chain.
- The shared test process: the v6 guard tests patched the order with a class decorator. A class decorator restores
  the value when the test method returns. Two of these tests set up a nested openness case, and the cleanup of that
  case ran after the method and wrote `(v6,)` back. The capacity guard runs these tests among its evidence, so in
  general shard 2 every later test ran under `(v6,)`. Two tests that check the order `(v7, v6)` failed, and one test
  that expects a v6 single turn passed only because of the leaked order.
- The tests of the supplied text: the supplied reading journey matched the sentence of the v6 prompt, but its chain
  now starts under v7. The v7 prompt has its own text about a supplied text, and a v7 reading turn delivers the
  reported origin in the audit notices record.
- The tests of the stop groups: the closing test of the series code groups admitted only the groups `stored_state`
  and `named_cause`. 0.91.0 added the group `visual_text_reading` for `review_visual_text_route_required`.

## What changed

- `prepare_packet` keeps a math openness packet that one input of its route holds as one native turn. A new problem
  openness review still starts a chain under the first protocol of `(v7, v6)` whose admission accepts it.
- `V6GuardTests` starts its patch of the order in `setUp`, with the first cleanup. The patch is now stopped after the
  cleanups of every nested case, so the released order is restored. A new test of `test_fixture_isolation` runs a v6
  guard test with its nested case and checks the order after it. It failed before the fix.
- The supplied reading journey pins its chain to v6. A new test runs a supplied text through a v7 chain for the
  three shapes (a saved PDF, a Markdown document and a question with its answer). The reading prompt explains a
  supplied text, a reading turn delivers the audit notice with the reported origin, and the finding records.
- The closing test of the series code groups admits a group with its own next step under the conditions that the
  group declares.
- The alternate representation test checks that a v7 chain reads only the selected representation. A second test
  keeps the v6 single turn of a small packet.
- Incident ledger entries `release-0910-math-openness-single-turn`, `release-0910-v6-guard-order-leak` and
  `release-0910-tests-of-the-earlier-default`.

## Checks

Before the pull request, the changed test modules passed on Python 3.12 and 3.9, and so did the harness test of the
single math turn and the incident ledger test. The complete general suite ran on Python 3.12 in eight parallel
parts, with a check of the order after every test. `codex/generate.py --check`, `git diff --check` and the release
record check passed. The CI of the pull request runs the full suites on Python 3.9, 3.12 and 3.14, and the pull
request merges after its CI passes.

## Compatibility

No file of a reviewer route's runtime identity changes, so no route becomes stale. Stored records, packets, prompts
and requests keep their meaning and their digests. A math openness review that 0.91.0 started as a reading chain
keeps its chain.
