# Exactory 0.43.0

This release makes a manuscript account for the literature that its study used.
It adds no stored record kind. The research constitution stays at version 5, and
no study revalidates.

## Citation accounting at the manuscript pin

A study can read many sources in full and still cite few of them. The pin now
compares the pinned bibliography with two sets of works:

- every work with a recorded full-text reading
- every work that a selected research search of the five purposes cites

A work has three kinds of citation evidence: its arXiv family, a DOI of the work
or of a provider alias, and its title when the title has two or more words. In a
BibTeX bibliography, an entry cites the work when it carries one of the
identifiers as a whole identifier. An entry also cites the work when its title
field is the work's title. Text outside the entries is not evidence. The lineage
gate reads the same evidence.

The pin lists each accounted work that the bibliography does not cite. Each of
these works needs one item in the new optional payload field
`citation_accounting`:

- `{"work_id": ..., "cited_as": "<key>"}` names the BibTeX entry that cites the
  work. Use it for a published version that the store does not link to the
  preprint that the study read.
- `{"work_id": ..., "reason": ...}` states why the paper does not cite the work.

If a listed work has no item, the pin stops with
`citation_accounting_incomplete`. The error gives each work and the reason that
the pin accounts for it: `fulltext` or `search:<purpose>`. A wrong item stops the
pin with `invalid_citation_accounting`. Its details give the item index and the
cause: `fields`, `already_cited`, `unknown_work`, `duplicate`,
`cited_as_and_reason`, `neither` or `unknown_key`. The bundle keeps the result as
`citation_accounting: {cited, not_cited}`, so the decision is part of the bundle
digest.

The lineage gate now uses the whole-identifier and whole-title rule. Before this
release, a DOI that was the start of another DOI counted as a citation. A title
inside a longer title also counted.

## `exactory-check`

- `add --arxiv-id` cites the published version of a preprint. It first checks
  each DOI that the arXiv record names. Otherwise it searches Crossref for
  exactly one record with the same title, from the year before the preprint or
  later. Both routes need a journal, proceedings or chapter record with the same
  first and second authors. The command prints which version the entry cites
  and why. `--preprint` keeps the preprint.
- `add` refuses a work that the bibliography already holds under any key.
- `add` renders the inline markup of Crossref and DataCite titles as LaTeX:
  `Sb<sub>2</sub>Te<sub>3</sub>` becomes `Sb$_{2}$Te$_{3}$`. An inline MathML
  formula, as in many APS titles, becomes LaTeX with a space on each side. Only
  registry tag names are markup. Other text in angle brackets stays title text.
- The lookup cache uses only the primary identity of an entry: the DOI, else the
  arXiv identifier, else the title. The cache file has schema version 2, and
  `lookup` ignores a cache from an earlier release.
- `lookup` reads the manuscript next to the bibliography: the main file and the
  files that it includes. The main file is the file that `--main` names, else
  `paper.tex`, else the only LaTeX file with `\documentclass`.
- In the manuscript, an entry that no citation command cites is blocking.
  `\nocite` does not count as a citation. Comments, `\iffalse` blocks and
  comment environments do not count either.
- A sentence that makes a prior-art statement without a citation is a warning
  with its file and line.
- The report has a new `manuscript` object with the main file, the SHA-256 of
  each file read, the uncited entries and the warnings. `counts` still describes
  the registry status of each reference. The top-level `blocking` count also
  includes the uncited entries.
- `gate` treats the report as stale when the manuscript files change. It also
  treats a report without a `manuscript` object as stale.

## Skills

The write skill asks for the published version of each cited paper. It asks for
the exact preprint version wherever a value comes from a preprint. It asks for
`citation_accounting` at the pin. Its stage report includes a citation map by
the five purposes, and the original source of each named law, model, method and
tool. The evaluate skill treats uncited entries as blocking findings.

## Upgrade

1. In each draft workspace, run `exactory-check lookup` again. A report from
   0.42.2 has no `manuscript` object, so `gate` treats it as stale.
2. If the draft has several LaTeX root files and no `paper.tex`, add
   `--main <file>` to `lookup`.
3. If `lookup` lists an uncited entry, cite the entry where it supports a
   statement. Otherwise, remove the entry.
4. At the next `exactory-research manuscript` pin, add `citation_accounting`
   items for the works that the pin lists. Bundles pinned before 0.43.0 do not
   change.
