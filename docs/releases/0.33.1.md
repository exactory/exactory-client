# Exactory 0.33.1

This version includes the Claude Code and Codex entrypoints, all 14 shared
skills, and the corresponding hooks.

The math-solver and AI Science continuation hooks now return control to the
user after their cap summary. After that pause, a new user turn starts a new
continuation budget.
Both hosts use these shared handlers. Host limits still apply: Claude Code
ends a turn after eight consecutive Stop blocks, so identical plugin caps do
not guarantee identical uninterrupted run lengths. See the
[Claude Code Stop reference](https://code.claude.com/docs/en/hooks#stop).

Claude's math Stop timeout is now 30 seconds, matching Codex, so the hook
can finish its status lookup, which has a 20-second internal timeout.

The Codex adapter accepts whitespace around patch boundary markers while
retaining the checks on protected files.

The runtime guide now states Python 3.9+ and preserves the shared workflow's
authorization and pacing rules. It also identifies the option for independent
reviewers with fresh contexts.

## Version history

The `exactory--v0.33.0` tag points to the source before the Codex entrypoints
were added. Later main commits included Codex support but retained version
`0.33.0`. Version `0.33.1` gives the combined package its own version.

## Installation

After this version is published, the public `exactory/marketplace` catalog
installs it through the normal commands in the [README](../../README.md).
Codex users must review and trust the hooks in `/hooks` after the update.

This document describes the release contents. Its presence does not mean
that the Git tag or GitHub Release is published.
