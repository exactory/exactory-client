# Exactory 0.35.0

This is an experimental initial release of the shared research foundation.
Both plugin manifests identify version `0.35.0`. Broader skill workflow updates,
CI and host distribution work, end-to-end validation, and independent
implementation review continue for `0.35.1`.

## Included implementation

- `exactory-research` exposes the shared research store, exact source and reading
  records, research and verification profiles, literature preparation, and
  current evidence assessments.
- Managed author workflows check prospective execution admission, retained
  outcomes, the current research candidate, and independent review inputs before
  the applicable manuscript and publication transitions.
- Verification binds the exact task and outgoing verdict body to current local
  preparation. Soundness remains separate from novelty and impact, and verifiers
  must not read other verdicts before filing their own.
- The native math controller consumes the shared foundation while retaining its
  own proof acceptance, resource accounts, lineage, and recovery rules.

The [Research CLI guide](../research-cli.md) documents the implemented command
order, complete illustrative payloads, current gates, and recovery interfaces.
The [research constitution](../../RESEARCH_CONSTITUTION.md) states the common
policy and the limits of mechanical checks. Completing records does not establish
scientific truth, comprehension, novelty, or practical benefit.

The earlier source changes documented in the [0.34.2 notes](0.34.2.md) remain
included. Those historical notes are preserved separately.

## Validation at the initial packaging checkpoint

On development candidate `f5b3c46bb22424f3a0d5e836ba9c21e7fbcff51c`, the focused
Task 6 suite passed 134 tests on each of Python 3.9.6 and Python 3.13.8. The full
native math harness passed 601 tests on Python 3.13.8. The full root suite was
still pending when this initial package was prepared.

These results do not complete the broader guidance, CI matrix, staged host
distribution, end-to-end research validation, or independent implementation
review. That work and any resulting fixes continue for `0.35.1`. This packaging
update changes release metadata and documentation; it does not relax a research,
execution, proof, publication, or verification gate.

## Compatibility and upgrade

The commands support Python 3.9 or later on macOS and Linux with the standard
library. PDF text extraction additionally requires an installed `pdftotext`;
missing extraction support leaves the relevant reading obligation pending.

Existing workspaces require explicit adoption and current preparation where the
CLI reports it. Historical receipts and archived evidence remain history.
Constitution changes require explicit adoption and reassessment of dependent
decisions. Follow the CLI guide's status and recovery instructions before fresh
work. Updating does not resume paused research, reset budgets, or automatically
make an old decision current. Upgrade all writers before using one research root
with this version, and preserve pending recovery work.

For Claude Code:

```sh
claude plugin marketplace update exactory-ai
claude plugin update exactory@exactory-ai
claude plugin list --json
```

For Codex:

```sh
codex plugin marketplace upgrade exactory-ai
codex plugin add exactory@exactory-ai --json
codex plugin list --marketplace exactory-ai --json
```

Preserve the installation scope. Confirm that the returned version and installed
manifest identify `0.35.0`, then start a new session and review and trust changed
hooks through the host's supported flow. Do not edit a running installed cache.
