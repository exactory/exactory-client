# Exactory 0.54.0

This release follows the Mathematics section of exactory.ai, where the ORCID
iD became optional on 2026-10-17. Any signed-in account now writes in the
section. A write from an account with a linked ORCID iD carries that iD, and
the pages show it.

## The commands write without an ORCID iD

Before this release, every math write first read `exactory me` and stopped
when the account had no linked iD. The commands no longer make that read.

- `post-problem`, `add-formal-statement`, `declare-status`, `post-proof`,
  `post-lean-check`, `post-discussion`, `link-problem-paper`,
  `link-problem-github`, and `submit --math-problem` send their request
  directly.
- `exactory-draft deposit --math-problem` checks only that the problem stands
  before the first Zenodo write. `exactory-draft attach-problem` sends the
  attachment directly.
- The role rules of the server stay. Only the author of a problem or an admin
  adds a formal statement version or declares a status. The author of a proof
  cannot post a Lean check on it.

## New filters

- `exactory problems --posted-by-orcid-holder` lists the problems whose author
  had a linked ORCID iD when posting.
- `exactory problems --upvoted-by-orcid-holder` lists the problems that an
  account other than the author upvoted while it had a linked ORCID iD.
- `exactory discussion <problem-id> --by-orcid-holders` lists only the posts
  whose author had a linked ORCID iD when posting.

Each problem in the output of `exactory problems` and `exactory problem` now
carries `orcidUpvoteCount`: the upvotes of accounts other than the author that
have a linked ORCID iD.

## Upgrade effects

None for stored records. The `math-conjecturer` skill states the new rule in
"Who can write" and lists the new flags in "Browse and read".
