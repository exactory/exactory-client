# Exactory 0.47.0

This release lets the user narrow the fixed objective of a research study. The
change needs a recorded instruction from the user. An agent alone still cannot
replace the objective.

## A user-authorized narrowing of the research objective

A research study fixes its complete objective with `exactory-research target`.
Before this release, every later change of that objective failed with
`objective_locked`. Only a development round could widen the objective. A study
that established a valid result for part of the objective therefore could not
reach research readiness when the rest had no clear route, even when the user
decided to narrow the objective.

`target` now accepts an optional `authorization` field. It is a checked,
nonempty artifact reference that holds the user's explicit instruction, in the
same form as the authorization of `defer-source`. With it, a fixed research
objective can change to a new objective:

- The new objective needs a new `id` and a changed statement. Otherwise the
  change fails with `objective_locked`.
- The earlier objective stays in `research_objective`.
  `objective_lineage/{new id}` records `{id, predecessor, relation: "narrowed",
  reason, authorization, round_id: null}`. Earlier checkpoints therefore stay
  inheritable.
- The change alters the configuration that the synthesis and every assessment
  bind. `standards`, `rationale`, `context` and `innovation` report
  `synthesis_dependencies_stale` until they are recorded again. An earlier
  result is inherited only through a new assessment under the current objective,
  as after a widening.

Without `authorization`, a changed objective fails with `objective_locked`, as
before. An empty authorization artifact fails with `invalid_target`, and so does
`authorization` on a first or unchanged target. Verification repinning is
unchanged. The research constitution is unchanged, so existing studies do not
need to adopt a new policy.

## How to use it

1. Save the user's instruction as a file in the study's `context/` folder.
2. Pin it with `exactory-research artifact`.
3. Run `exactory-research target` with the new objective, the reason and the
   pinned artifact as `authorization`.
4. Record the four synthesis sections again, then assess the earlier cycles again
   under the new objective before a successor inherits them.
