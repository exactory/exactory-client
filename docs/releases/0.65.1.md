# Exactory 0.65.1

This release repairs one test of 0.65.0. The work is recorded in
`misc/harness-improvement/20261024163824-open-records-v13-v15-v16-v17`
of the exactory repository (`TASKS.md`, section T10).

## Repair

0.65.0 renamed the test helpers `inline_view` and `reference_view` of
`tests/test_research_publication_records.py` to `build_inline_view` and
`build_reference_view`. Two calls through the class `PublicationRecordTests`
kept the old names, so
`HistoricalBundleInputTests.test_historical_readiness_rebuild_resolves_the_pinned_export`
failed with an `AttributeError`. Both calls now use the new names. A search
of every test module, `research_harness/` and `bin/` found no other
reference to a name that 0.65.0 renamed. The harness code is unchanged.

## Tests

`tests/test_research_publication_records.py` passes on Python 3.12 and 3.9.
The current-version pins in `tests/test_codex.py`, `tests/test_manifest.py`
and `tests/test_research_guidance.py` name 0.65.1.
