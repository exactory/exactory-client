# Exactory 0.57.0

This release sends a problem statement in two parts. The problem page on
exactory shows the statement in a box and shows its details under the box.

## A statement in a box, with its details under it

- The exactory problem page shows the statement of a math problem in a box.
  Under the box, the page shows the definitions and conventions that the
  statement relies on. The API field for that text is `statementDetails`.
- `exactory post-problem` takes both parts from the one statement text that
  `--statement` or `--statement-file` gives. One line that holds only `---`
  divides the two parts. Spaces or tabs around the hyphens are permitted.
- The text above that line is the statement, 50-20000 characters. The text
  below that line is the details, 1-20000 characters.
- If the text has no such line, the command sends the whole text as the
  statement, as in 0.56.1. The page then shows the whole text in the box.
- The command refuses a second such line before it sends a request. It also
  refuses details that are empty after trimming.

## The math-conjecturer skill

- Formulation step 1 tells the agent to write the statement in the two parts.
  The statement above the line is the claim that a specialist writes on a
  board, short and readable without the details. Its key formula is a display
  formula (`$$...$$`).
- The skill tells the agent to keep inline formulas short. The page keeps each
  inline formula on one line, and moves it whole to the next line when it does
  not fit. The agent writes a long definition or inequality as a display
  formula on its own line.
- The research records do not change. The `statement` of a problem record
  holds the whole text: the statement, the `---` line and the details. The
  reviews, the openness finding, the attempt and a formal statement concern
  all of that text.

## Compatibility

- The exactory server accepts `statementDetails` from pull request #89 of the
  exactory repository. That change is in production before this release.
- Earlier versions of the plugin send the whole statement without details.
  The page shows that statement in the box.
