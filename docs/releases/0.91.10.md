# Exactory 0.91.10

This release corrects one test. It changes no code of the harness, no command and no text that a user reads. The
release follows 0.91.9. Its record is
`misc/harness-improvement/20261119212253-impact-of-a-resolution-lineage-and-future` of the exactory repository.

## What changed

- The test `tests.test_review_request_parity` builds 21 cases of reviewer calls. It compares their requests, their
  packets and their reports with values that are frozen at one earlier commit.
- Six of the cases build their problem record with the default statement of the test fixtures. Release 0.91.8 made
  that default statement longer, because `problem-statement` now refuses a new statement of fewer than 50
  characters. The requests of the six cases then had other bytes than the frozen values.
- The test failed in the CI of 0.91.8 and of 0.91.9 on `main`. It was not in the checks that ran before the pull
  request of 0.91.8.
- The cases now build the statement that the frozen values hold, and they record it without the rules of the post.
  The frozen values are unchanged.

## Checks

On the tree of 0.91.9, `tests.test_review_request_parity` failed with 56 differences in six cases, on this
machine as in the CI. With this change its 24 tests pass on Python 3.12 and 3.9.

The CI run of 0.91.8 on `main` had 15 failed jobs: the general shards 2 to 6 on Python 3.9, 3.12 and 3.14. Their
logs name 168 failures, and each of them is in this test. No other test failed in these jobs.

Before the pull request, these checks passed on Python 3.12 and 3.9: 10 test modules (173 tests on each), which
are this test, the tests of the version, the manifest, the guidance, the release records and the incident ledger,
and four test modules whose fixtures the cases use. `codex/generate.py --check` and `git diff --check` passed.

The release record check reports only that 0.91.10 has no tag and no GitHub release yet. It runs again after the
tag. The CI of the pull request runs the full suites on Python 3.9, 3.12 and 3.14.

## Compatibility

No code of the harness changes. Stored records, requests, prompts and digests are those of 0.91.9. No reviewer
route becomes stale.
